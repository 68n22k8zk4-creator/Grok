# Огонёк (OgonekApp)

iOS-приложение: погода + график смен + питомец-огонёк + учёт трат.

## Стиль
Тёмный минималистичный UI в фиолетово-оранжевых тонах, как на референсах.

## Возможности

### 🌤 Погода
- Реальная погода через Open-Meteo (без API-ключа)
- Выбор города (Прага, Киев, Москва, Варшава, Берлин и др.)
- Подсказки: как одеться + нужен ли зонт
- Прогноз на 5 дней + влажность/ветер/давление/закат

### 📅 Смены
- Ручной режим: «Начать смену» → перерыв/обед → «Закончить»
- Авто-режим шаблонов (можно расширить)
- Календарь с отметками рабочих дней
- Подсчёт часов и заработка (ставка в час + бонус серии)
- Серия дней подряд → бонус +20%

### 🔥 Огонёк (питомец)
- Кормление с выбором еды (полезная / обычная / фастфуд)
- История питания и «лучшая еда сейчас»
- Игры: крестики-нолики, память, угадай число
- Статы: сытость, счастье, здоровье, уровень, серия
- Нельзя постоянно кормить фастфудом — здоровье падает

### 💳 Траты
- Добавление расходов по категориям
- Лимит на месяц + прогресс
- История и средний чек

### 📱 Виджеты
- Small / Medium / Large
- Обновляются автоматически (WidgetKit timeline ~15 мин)
- Показывают уровень питомца, часы, заработок, серию

## Как открыть и собрать

1. Распакуй ZIP на Mac (или через GitHub → Codespaces / Mac).
2. Открой `OgonekApp.xcodeproj` в Xcode 15+.
3. Выбери свою команду (Team) в Signing & Capabilities.
4. Bundle ID: `com.ogonek.app` (можно поменять).
5. Для виджетов желательно добавить App Group `group.com.ogonek.app` и шарить UserDefaults.
6. Собери на симулятор или устройство.

### Через CodeMagic + GBox
- Залей репозиторий на GitHub.
- В CodeMagic укажи Xcode project / scheme `OgonekApp`.
- Подпиши своим `.p12` + provisioning profile.
- Скачай IPA и установи через GBox Fun.

## Что можно доработать
- Кастомные иллюстрации питомца (заменить emoji на ассеты из референсов)
- App Group для синхронизации данных с виджетом
- Больше городов / геолокация
- Редактирование прошлых смен вручную
- Больше игр (дурак, 21, морской бой)
- Локализация полностью на русский
- iCloud backup

Минимальная нагрузка: данные в UserDefaults, погода только по запросу, виджет обновляется раз в 15 минут.
